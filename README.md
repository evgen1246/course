### Финансовый виджет
## Описание:
Проект представляет собой набор инструментов для анализа банковских транзакций, получения актуальных курсов валют и стоимости акций с последующим формированием JSON-ответов для веб-виджета.

# Установка и запуск:
```
bash
poetry install
```

# Настройка
Создайте файл .env:
```

env
TOKEN=your_apilayer_token
API_KEY_STOCKS=your_alphavantage_key
```

Создайте файл user_settings.json:

```

json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

Функции:
- transaction_convert
Описание: Конвертирует сумму транзакции в рубли. Если валюта RUB, возвращает исходную сумму, иначе выполняет запрос к внешнему API.

- get_greeting
Описание: Возвращает приветствие ("Доброе утро", "Добрый день", "Добрый вечер", "Доброй ночи") в зависимости от текущего времени.

- get_card_spending
Описание: Принимает список транзакций, возвращает статистику по картам: последние 4 цифры, общую сумму расходов и кэшбэк (1 рубль на каждые 100 рублей).

- determine_category
Описание: Определяет категорию транзакции на основе описания (Супермаркеты, Фастфуд, Топливо, Развлечения, Медицина, Переводы, ЖКХ и др.).

- get_top_transactions
Описание: Возвращает топ N транзакций по абсолютной сумме (по умолчанию 5). Включает дату, сумму, категорию и описание.

- get_financial_data
Описание: Получает курсы валют (API ЦБ РФ) и цены акций (Alpha Vantage API) на основе настроек из user_settings.json.

- load_transactions_from_file
Описание: Загружает список транзакций из JSON-файла. В случае ошибки возвращает пустой список.

- format_transaction_date
Описание: Преобразует дату из форматов YYYY-MM-DD HH:MM:SS, ISO или YYYY-MM-DD в формат DD.MM.YYYY.

- get_transfers_to_individuals
Описание: Возвращает транзакции-переводы физическим лицам (категория "Переводы", в описании есть имя и инициал с точкой, например "Валерий А.").

- spending_by_category
Описание: Возвращает DataFrame с тратами по заданной категории за последние 3 месяца (от переданной или текущей даты).

- pending_by_category_json
Описание: Возвращает JSON-ответ с тратами по категории за последние 3 месяца.

- main
Описание: Главная функция, принимает строку с датой и временем в формате YYYY-MM-DD HH:MM:SS, возвращает JSON-ответ с приветствием, статистикой по картам, топ-5 транзакций, курсами валют и ценами акций.
